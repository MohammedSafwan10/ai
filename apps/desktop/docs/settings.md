# Desktop settings

Settings uses a shared navigation and row layout. General controls appearance and tray behavior; failed saves remain visible. Providers lists connections separately, with account and model controls inside each provider. Workspace lists detected applications as actions for the current project, with loading and launch errors shown. It does not change default applications.

About shows the installed version, current update status, latest release metadata, and expandable notes. Check and restart actions use the existing desktop updater. Errors are recoverable and duplicate clicks are ignored. Website and source links open in the external browser.

Shortcuts is searchable and grouped by Chat, Model picker, App and view, and Saved prompts. It documents implemented handlers and their focus conditions. Ctrl+/ (Command+/ on macOS) opens Shortcuts directly, including when settings was closed. Zoom uses the native window handler. Reload is not advertised because its application-menu shortcut is enabled only in development. Enter does not submit while an IME is composing.

See [storage-cleanup.md](storage-cleanup.md) for cleanup behavior and [provider-model-catalogs.md](provider-model-catalogs.md) for model discovery.
